# Automatic Parking Gate System

## Overview
This project is an Arduino UNO-based Automatic Parking Gate System. It detects an approaching vehicle using an ultrasonic sensor and automatically opens the gate using a servo motor. After the vehicle passes, the gate closes automatically.

## Features
- Automatic vehicle detection using an ultrasonic sensor
- Servo motor-based gate opening and closing
- Contactless parking gate operation
- Simple and low-cost Arduino project

## Components Used
- Arduino UNO
- HC-SR04 Ultrasonic Sensor
- SG90 Servo Motor
- Breadboard
- Jumper Wires
- USB Power Supply

## Technologies Used
- Arduino IDE
- Embedded C

## Working
The ultrasonic sensor continuously measures the distance to detect a vehicle. When a vehicle comes within the set range, the Arduino rotates the servo motor to open the gate. After a few seconds or when the vehicle moves away, the gate closes automatically.

## Applications
- Smart Parking Systems
- Residential Parking Gates
- College and Office Parking Entry
- Toll Gate Automation
